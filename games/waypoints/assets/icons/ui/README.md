# UI icons

Two symbols from **Material Symbols** (Google), rounded weight 400, taken from
the `@material-symbols/svg-400` package on npm at version 0.47.5 and copied here
unchanged:

| file | the library's name |
|---|---|
| `pinch-zoom-in.svg` | `rounded/pinch_zoom_in.svg` |
| `mouse.svg`         | `rounded/mouse.svg`        |

Licensed under the Apache License 2.0, the same as the rest of Material Symbols.
A copy of that licence is in `LICENSE-material-symbols.txt`.

They are drawn as CSS masks rather than `<img>` so they take the interface's own
colour — the file is the library's artwork, the tint is ours.
