Sound lab

Exactly what the game plays: the three lane tracks and every effect, grouped by where you hear it. Each effect shows the file it plays (leading silence is trimmed automatically). Adjust levels, pitch spread (each play picks a random pitch within ±N semitones, so repeats don't sound identical) and the mix, then press Save to game. The game reads these settings when it starts.
