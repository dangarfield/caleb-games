# Linky

A Flow Free clone. The player drags colored pipes across a grid to connect each
pair of matching dots. Pipes can't cross; a level is solved only when **every
dot pair is connected AND every cell on the board is covered** (classic Flow
Free 100%-coverage win). 50 levels ramp from 5x5 to 9x9 with rising pair counts.

## Features
- **Player select (Caleb / Ezra)** with separate progress, stored under
  `calebArcadeData.linky.<player>` (`{ unlocked, completed }`).
- **50 provably-solvable, fully-covering levels**, generated by construction and
  self-verified. Level curve: L1-10 = 5x5, L11-20 = 6x6, L21-32 = 7x7,
  L33-42 = 8x8, L43-50 = 9x9. Pair counts ramp 5→8 (5x5) up to 13→19 (9x9).
- **No more than 25% of a level's pairs may have their two dots on adjacent cells**
  — a generator quality gate (checks endpoint adjacency, not just 2-cell paths) so
  levels stay puzzles rather than a row of one-step gimmes.
- **Drag-to-connect** input (pointer events; touch + mouse). Dragging over an
  existing pipe truncates it back to the collision point; dragging back over your
  own path retracts it (standard Flow Free behavior).
- **Hint** button — fills in the next unfinished color's full solution path from
  the stored solution (truncating any conflicting pipes first).
- **Undo** (60-step history) and **Clear board** controls.
- **Level map** screen with locked / unlocked / solved states and star markers.
- Canvas HUD pill (level #, pairs linked, coverage % + bar), canvas win screen
  with confetti, Web Audio SFX (blip, connect chime, error buzz, win fanfare).
- Per-region translucent color wash on covered cells, matching the Flow reference.
- **`?selftest`** URL param re-runs the level verification in-browser and prints
  PASS/FAIL per level to console and on-screen.

## File structure
- `index.html` — the whole game (Canvas 2D, no build step). Player select, level
  map, board rendering, drag logic, HUD, win screen, SFX, self-test.
- `levels.js` — auto-generated `window.LINKY_LEVELS` (50 levels: `size`,
  `pairs:[{color,a,b}]`, `solution:[[[r,c]...]...]`). ~32 KB. Do not hand-edit.
- `tools/gen-levels.mjs` — Node generator. Builds a random Hamiltonian path over
  the full grid (boustrophedon seed + backbite randomization), cuts it into K
  contiguous segments (each = one color pair, ends = the dots), self-verifies
  every level, and aborts on any failure. Seeded mulberry32 PRNG for
  reproducibility. Run: `node games/linky/tools/gen-levels.mjs`.

## Key design decisions
- **Solvability by construction, not by search.** A single Hamiltonian path
  partitioned into contiguous segments guarantees full coverage and zero overlap
  automatically — the stored solution is literally the generator's own partition.
- **The stored solution doubles as the hint source and the self-test oracle.**
  The runtime `?selftest` runs the *same* checks as the generator: adjacency,
  endpoint match, no overlap, full coverage.
- **Quality gates** reject partitions where >25% of pairs have adjacent endpoints,
  or too many fully straight-line paths (stricter for boards >=7x7), so levels
  aren't trivially obvious. Adjacency is measured on the endpoints, not the path
  length — a long snaking path that happens to loop back next to its start still
  counts as an adjacent-dot gimme.
- **Win = all connected AND full coverage**, matching Flow Free — not just
  connecting the pairs.

## Memory
- Built via `new-game` recipe; `game-reviewer` verdict = pass (0 defects). All 50
  levels verified in-browser via `?selftest` and independently by the orchestrator
  (adjacency, endpoint match, no overlap, coverage == size²).
- Dev-server quirk (not a game bug): the port-3000 dev server strips `.html`, drops
  the `?selftest` query, and 404s `levels.js`. Run the self-test via the `file://`
  path instead (`file://…/games/linky/index.html?selftest`). Production back link
  `../../index.html` is correct regardless.
