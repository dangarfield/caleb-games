# 2048

Sliding tile puzzle game. Touch-optimized with swipe controls, score tracking with localStorage persistence, win/game-over states, and animated tile merges.

## Features
- 4x4 grid with smooth tile sliding and pop animations
- Swipe touch controls + arrow key support
- Score tracking with localStorage-persisted best score
- Win overlay at 2048 with "Keep Going" option
- Game over detection and retry
- Easy mode: skips adding new tiles after non-merge moves
- Classic 2048 color scheme, responsive sizing

## Easy Mode Fix
Easy mode skips adding tiles when no merge occurs. This could cause deadlock when only non-matching tiles remain. Fixed by adding `canMerge()` — checks if any two same-valued tiles share a row or column. If no merge is possible, a new tile is added even in easy mode.
