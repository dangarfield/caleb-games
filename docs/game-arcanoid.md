# Arcanoid

Breakout/Arcanoid clone with Canvas API. Touch drag to move paddle, multiple levels, power-ups, and detailed graphics.

## Features
- 7 levels with different brick layouts
- 12 power-ups: laser, fireball, shield, magnet, mega ball, ghost ball, extra life, multi-ball, wider paddle, plus negatives (shrink, speed up) — all with hand-drawn circular icons
- Multi-hit bricks with crack effects
- Indestructible metallic bricks (levels 2-7) — ball bounces off with spark particles
- Animated nebula background, metallic paddle, screen shake
- Particle trail behind paddle when moving
- Score tracking
