# Tenacity

Precision platformer with virtual d-pad for tablet controls.

## Features
- D-pad overlay (bottom-right, 150x150px) with up/down/left/right arrows
- Keyboard controls (arrow keys / WASD) still work alongside d-pad
- Game canvas centered with black background using flexbox wrapper
- Canvas capped at 16:9 aspect ratio

## History
Originally used raycasting for touch controls, which was unreliable due to varying camera angles. Replaced with simple d-pad overlay that fires the same key flags as keyboard.
