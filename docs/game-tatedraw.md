# Tate Draw

Embedded drawing canvas powered by the Tate museum's online drawing tool.

## Features
- Full-screen iframe embedding of draw.tate.org.uk
- Back button overlay to return to arcade hub
- All drawing features provided by the external Tate Draw application

## Technical
- Simple iframe wrapper with fullscreen allow
- Backdrop-blur styled back button with fixed positioning
