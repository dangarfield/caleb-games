# caleb-games

A collection of browser-based games for Caleb to play on his tablet. All games are touch-optimized, self-contained HTML files with no external dependencies.

## Games

- **2048** - Slide and merge tiles to reach 2048
- **Arcanoid** - Breakout clone with 12 power-ups
- **Archers** - Archero-style wave shooter
- **Archers 3D** - 3D archery game
- **Battleship** - Salvo-based firing with cinematic view
- **Bomberman** - Place bombs and blast your way through
- **Bottle Sort** - Liquid sort puzzle with tilt pour
- **Bubble Shooter** - Aim, shoot, and pop matching bubbles
- **Captain Callisto** - Space platformer (WebGL)
- **Clash of Space** - Twin-stick space shooter
- **Conquer** - Territory conquest
- **Connection** - Shape-tracing puzzle with progressive difficulty
- **Count Master** - Number runner
- **Crazy Eights** - Card game with AI
- **CyberStream** - Swipe-only runner
- **DR1V3N WILD** - 3D racing with player select
- **Drift Racer** - Top-down drift racing with track editor
- **Endless Runner** - Jump and duck to survive the run
- **Fling** - Physics flinging game
- **Free Kick** - 3D perspective penalty kicks
- **Frogger** - Cross the road and river to reach home
- **Fruit Ninja** - Swipe to slice fruit, avoid the bombs
- **Happy Glass** - Physics-based drawing puzzle
- **InfiniJump** - Vertical platformer
- **Minesweeper** - Classic mine sweeper
- **Pac-Man** - Chomp dots and dodge the ghosts
- **Paperboy** - Deliver newspapers while dodging obstacles
- **Petri** - Cell growth game
- **Racer 13** - Psychedelic lane racer
- **Rock Paper Scissors** - RPS with custom sets
- **Sensible Soccer** - Top-down 11v11 football
- **Shed** - Custom rules card game
- **Snail** - Snail trail puzzle
- **Snake** - Eat food, grow longer, don't hit yourself
- **Solitaire** - Klondike solitaire
- **Tate Draw** - Drawing canvas
- **Tenacity** - Precision platformer
- **Tetris** - Classic Tetris with SRS rotation and touch buttons
- **Tilt Maze** - 100-level physics-based 3D tilt maze
- **Tower Defense** - Build towers and stop enemy waves
- **Tower of Hanoi** - Disc-stacking puzzle with undo
- **Treehouse Quiz** - Treehouse book series trivia quiz
- **Tron** - Neon lightcycle battle vs AI
- **Whack-a-Mole** - Tap the moles before they hide
- **Worms** - Turn-based artillery with destructible terrain

## Local Development

Requires [serve](https://www.npmjs.com/package/serve) (`npm install` to set up):

```bash
npm install
npm start
```

This runs `serve .` on port 5000 — open http://localhost:5000 in your browser.
